# StirringSpoonRecipe
This mod adds a carpentry recipe for the unused Stirring Spoon item.  
This mod needs to be on both the Client and the Server to work properly.  
This mod requires that you also have https://github.com/CG-Nik/CustomRecipesAPI downloaded to work properly.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.  

### Downloading
- Download StirringSpoonRecipe.zip off of the latest release.
- Extract StirringSpoonRecipe.zip and place the resulting StirringSpoonRecipe folder into your mods folder.
- Do NOT place the contents of the StirringSpoonRecipe folder into the Mods folder, place the StirringSpoonRecipe folder directly into the Mods folder.
